= lutaml-lml (transitional alias)

LML, the LutaML Model Language, now lives in the
link:https://github.com/lutaml/lutaml[lutaml] gem. This gem exists for one
deprecation window and only depends on `lutaml`.

Replace `gem "lutaml-lml"` with `gem "lutaml"`; `require "lutaml/lml"` is
unchanged. Graphviz output moved to
link:https://github.com/lutaml/lutaml-graphviz[lutaml-graphviz].
